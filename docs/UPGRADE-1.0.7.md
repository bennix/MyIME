# MyIME 1.0.7 本地构建记录

构建号 60，Apple Silicon（arm64），本地 ad-hoc 签名，未公证。本轮未上传 GitHub、发布 Release 或部署 Pages。

## 已实现

- 合并青简 92,825 条有效词条与频次，保留源读音；去重后词库共 1,160,989 条。
- 随包提供 227,688 条英文释义，可在设置中关闭；限制显示宽度并优先保留中文候选空间。
- `rq`、`sj`、`xq` 生成当前日期、时间、星期候选。主要格式位于常规首选后，其他格式稍后展示。
- 升级兼容旧偏好，不因新增字段重置设置；日期等字面候选不混入自造词学习。
- 修正候选被截断后的 `hasMore` 判断；更新来源、许可与构建文档。

原始 Brightmart 文件本次不在本机，复用已有字三元、词一元、词二元 TSV，分别含 300,000、250,000、900,000 条统计。本轮没有重训语料或内置 Transformer。

## 验证

- SQLite 完整性、去重、词源、释义与基础词覆盖校验全部通过。
- Swift 26 项测试通过，包括用户学习、临近成词、旧设置迁移、日期选择和延迟预算。
- 现有小型回归集：整句首选 30/30；常用词首选 40/40；多义词前三 21/21；简拼前五 9/10；错拼前三 6/6；尾部简拼前三 4/4。`sj` 同时提供时间快捷候选，“手机”未进入前五；这些数字不代表泛化准确率。
- Xcode Release 构建成功；最终应用签名校验通过，包内数据库与源数据库 SHA-256 一致。

本轮未替换系统中正在运行的输入法，尚未进行微信、便签等应用的交互实测。Transformer 接入限制与设计见 `NEURAL_RERANKING.md`。
