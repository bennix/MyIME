    安装只做一次

    打开应用，剩下的交给 MyIME。

    1. 下载

      从 GitHub Release 获取最新 DMG。

    2. 打开

      双击 MyIME，按提示授权自动安装。

    3. 切换

      在菜单栏输入法列表中选择 MyIME。

    适用于 macOS 26.5 或更高版本。当前版本尚未完成 Apple 公证；如果首次打开被阻止，请按住 Control 点击应用并选择“打开”。
