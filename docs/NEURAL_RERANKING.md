# 本地 Transformer 接入评估

当前实现：词库召回、词图整句组合、统计上下文评分和用户频次学习；不包含 Transformer 推理或模型权重。

参考项目：

- Qingjian：先产生整句路径，停键后异步重排前几条候选。公开仓库没有可直接打包的模型权重，权重许可另定。
- [Transformers4IME](https://github.com/VisualJoyce/Transformers4IME)：PinyinGPT 将拼音约束加入中文 GPT 解码，比无约束续写更适合输入法。
- Hugging Face 镜像 `aihijo/transformers4ime-pinyingpt-concat` 与 `aihijo/gpt2-zh-21k` 的模型卡标记 CC-BY-NC-SA-4.0；这不是禁止所有分发，但要求非商业用途、署名与相同方式共享，不能默认作为可自由商用资产打包。
- `uer/gpt2-chinese-cluecorpussmall` 模型卡未明确标出权重许可，须补充确认。代码的许可不能替代权重许可。

接入应先验证真实权重的分词器、拼音编码和数值一致性，再选择 Core ML 等离线运行方式。普通中文 GPT 权重本身不自动具备拼音约束能力。

运行约束：常规候选立即可用；停键约 80 毫秒后，在后台重排最多 6 条完整拼音候选。任务应绑定输入会话及递增版本号；新按键、选词、切换应用或停用输入法时使旧结果失效。用户已经移动候选高亮后不再改变其选择位置。模型失败、超时或缺失时继续使用统计候选。

不能把接口占位当作模型接入完成。正式启用前须以实际模型验证整句准确率、冷启动、内存、推理延迟、连续输入与跨应用切换，并检查模型输出不会突破输入拼音约束。
