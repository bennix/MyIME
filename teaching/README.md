# Teaching branch policy

`lab1-starter` through `lab12-starter` are entry points, not answer branches. Each
branch uses the common `TeachingStarter` package and replaces
`TeachingStarter/CURRENT_LAB.md` with one guide from `teaching/branch-guides/`.

Branch names are intentionally stable because the LaTeX textbook and GitHub
Classroom instructions refer to them. Never force-push a branch after students begin;
publish corrections as a small follow-up commit and announce the commit hash.

Do not publish `labN-solution` branches to a repository students can read.
