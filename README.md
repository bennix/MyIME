# MyIME course starter

This branch is a spoiler-minimized starting point for one MyIME course lab. It has
an independent Git history and intentionally contains no production MyIME 1.0.10
source code.

Read [`TeachingStarter/CURRENT_LAB.md`](TeachingStarter/CURRENT_LAB.md), then run:

```sh
swift test --package-path TeachingStarter
```

Create your own homework branch before editing. Do not merge `main` into this branch:
`main` is the complete reference implementation and textbook source.

For graded teaching, instructors should import this branch into a private GitHub
Classroom template so students cannot browse the reference branch.
